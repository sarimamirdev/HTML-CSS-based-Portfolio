# HTML & CSS Resume Portfolio

A personal resume website developed using HTML5 and CSS3. The website presents my introduction, educational background, technical skills, and contact information in a clean layout.

## Features
- Personal introduction and profile image
- Education and academic background
- Technical skills and programming languages
- Contact information with clickable links
- Gradient background and card hover effects
- Responsive viewport support

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Transitions and Hover Effects

## Project Structure
- `index.html` — Website structure and content
- `styling.css` — Styling, layout, colors, and animations
- `my resume img.jpeg` — Profile image
